Write down a memory. Lunara turns it into a constellation you can revisit — calmly, privately, and entirely on this device. Nothing you type is uploaded to a server.

Add a memory

Private by default: memories are stored only in this browser (localStorage). Use “Clear all” to delete them. No account, no upload, no tracking in this prototype.

Saved constellations

Click one to open it again. Each constellation is generated deterministically from its own words, so the same memory always draws the same sky.

    Lunara prototype for the Meta AI Developer Hackathon (Startup Track, Build for Your World). This is a working web prototype, not the iPhone app. The story text in this prototype is generated locally from templates; a future version can plug in a hosted model through the adapter described in README.md. No Meta API key is required to run it, and no claim is made about live Meta model usage in this build.
